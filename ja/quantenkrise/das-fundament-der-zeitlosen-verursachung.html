超時空因果の原理

// NPI公理系 (non potest intelligi)

実験が設定された時点で、結果はすでに固定されています。どのような行動をとろうとも、すべての経路と場所にはその目的地があらかじめ与えられています。動いているように見えるものは、真空の下に時間枠を超えて存在する基礎構造の表れに過ぎません。

// 定義: NPI (理解不可能な非物理情報)

非物理情報（NPI）とは、真空の下に存在する、論理的に不可欠でありながら概念的に把握不能な現実の基礎構造です。真空そのものがNPIの最初の論理的現れです。空間と世俗的な時間格子は、属性構造の時間的具現化を可能にするための二次的な副産物に過ぎません。

// 3つの仮説

// 仮説 01

属性構造の位置独立性

素粒子は因果的な軌道を持つ粒子ではなく、NPIの位置に依存しない純粋な属性構造です。古典的な軌道は存在せず、測定による時間的構築物に過ぎません。

[ 再現: 即時 ]
// 仮説 02

構造的等価性

素粒子の同一性は、NPI構造の絶対的な等価性によって決定されます。元の属性パターンは消失し、時空の一点から別の点へと超時空的に再具現化されます。

[ 運動: 時代遅れ ]
// 仮説 03

超時空の因果性

すべての属性形成の原因と論理的アンカーはNPIにあり、システム全体に静止した状態で同時に存在しています。無限に速い再形成が、時間が進む効果の錯覚を生み出します。

[ 錯覚: 時間の経過 ]

// 構造力学的メタファー: 水面波

水面波が進む際、水の粒子は輸送されず、水量がその場で上下するだけです。移動しているのは力の作用の乱れです。同様に、真空中を飛ぶ粒子は存在しません。

光子は属性構造の伝達と効果の時間化です。真の原動力を成すものはNPIの奥深くに定着しています。
