// 逻辑缺陷分析

// M理论 麦克斯韦时代

虚构运动的悖论

CM论点： 磁性仅由运动电荷产生。
NPI分析 (逻辑缺陷)： 永磁体静态地放在桌子上。它通过内部不可测量的虚构运动（安培环形电流）产生静态效应。CM捏造了一个不可见的原因。
感应悖论： 磁体运动时，适用变化场。线圈运动时，适用洛伦兹力。输出结果相同，但因果关系突然取决于参考系。
// N理论 量子时代

无定域自旋的悖论

CM论点： 电子的磁性源于内禀自旋。
因果关系的摧毁： 自旋被定义为没有空间延展的内禀角动量（点状电子），不可能属于经典旋转。
漏洞的捏造： CM将自旋定义为无原因的公理，以掩盖M理论的失败。一个无空间且无时间属性的物理量居然用来解释时空效应。
